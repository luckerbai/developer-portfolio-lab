# Developer Portfolio Lab — 页面原型结构

> **版本**：v1.0  
> **日期**：2026-09-22  
> **说明**：本文档定义所有页面的布局结构、分区模块、交互流程与响应式断点。所有线框均为结构示意，非视觉稿。

## 一、全局布局规范

### 1.1 公共布局结构

```
┌─────────────────────────────────────────────────────────────┐
│                        Header                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                        Main Content                         │
│                        (max-width 1200px, 居中)              │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                        Footer                               │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 Header 导航栏

**Desktop（>1024px）：**

```
┌─────────────────────────────────────────────────────────────┐
│  [Logo]   Home  Projects  Lab  Resume  About    [🌓] [⌘K] [GH]  │
└─────────────────────────────────────────────────────────────┘
```

- 左侧：Logo / 个人名字
- 中间：主导航（Home / Projects / Lab / Resume / About）
- 右侧：暗色模式切换 / Command Palette 按钮（⌘K 提示）/ GitHub 图标

**Mobile（<640px）：**

```
┌─────────────────────────────┐
│  [Logo]          [☰] [🌓]    │
└─────────────────────────────┘
```

- 左侧：Logo
- 右侧：暗色切换 + 汉堡菜单按钮
- 汉堡菜单展开为全屏抽屉式导航

### 1.3 Footer

```
┌─────────────────────────────────────────────────────────────┐
│  © 2026 Lucky · Built with Vue 3 + Vite + Supabase          │
│  [GitHub] [Email] [LinkedIn] [Twitter]                      │
│                                                             │
│  Home · Projects · Lab · Resume · About · Admin             │
└─────────────────────────────────────────────────────────────┘
```

### 1.4 响应式断点定义

| 断点名称 | 宽度范围 | 布局特征 |
|---------|---------|---------|
| **Mobile** | `< 640px` | 单列布局 / 汉堡菜单 / 卡片堆叠 / 触摸友好 |
| **Tablet** | `640px – 1024px` | 双列布局 / 折叠导航 / 简化网格 |
| **Desktop** | `> 1024px` | 完整导航 / 多列网格 / 最大内容宽度 1200px |

## 十、关键交互流程

### 10.1 项目发布流程

```
Admin 点击 "New Project"
    ↓
填写表单（Title / Summary / Tech Stack...）
    ↓
Zod 校验 → 错误则显示提示
    ↓
选择保存 Draft（仅自己可见）或 Publish（公开上线）
    ↓
写入数据库 + RLS 策略生效
    ↓
公开站点 Projects 列表自动更新（TanStack Query 失效刷新）
```

### 10.2 Command Palette 触发流程

```
用户按下 ⌘K / Ctrl+K
    ↓
全局 keydown 监听器捕获
    ↓
阻止默认行为，打开 Command Palette Modal
    ↓
焦点自动移入搜索输入框
    ↓
用户输入 → 实时过滤命令列表
    ↓
键盘 ↑↓ 导航 / Enter 执行 / Esc 关闭
    ↓
执行对应命令（路由跳转 / 切换主题 / 打开链接）
    ↓
关闭 Modal，焦点返回触发元素
```

### 10.3 登录鉴权流程

```
用户访问 /admin
    ↓
路由守卫检查 Supabase Auth 状态
    ↓
未登录 → 跳转 /admin/login
    ↓
输入邮箱密码 → Supabase Auth 验证
    ↓
成功 → 写入 session → 跳转 Dashboard
    ↓
失败 → 显示错误提示
    ↓
后续所有 Admin API 请求自动携带 token
    ↓
RLS 策略确保只有 admin 可写数据
```

## 十一、视觉设计原则

### 11.1 设计关键词

**Editorial / Minimal / Technical / Premium / Clean / Responsive**

### 11.2 参考气质

Linear · Vercel · Raycast · Stripe · GitHub · Notion

> 核心：像一个真正的软件产品，而不是一个"前端作品集模板"。

### 11.3 明确不做

- 满屏 3D 粒子 / WebGL 炫技
- 鼠标跟随特效
- 大量滚动动画
- 复杂 Landing Page 动效

> 技术展示放在 Lab 模块里，首页保持克制与专业。
