# ADR-004: Tailwind CSS 4 + CSS 变量设计令牌

**状态：** Accepted  
**日期：** 2026-09-22  
**关联文档：** [02-页面原型结构.md](../02-页面原型结构.md)

## 背景

平台需要统一的视觉系统（克制专业风格：Linear / Vercel / Raycast 式），并支持暗色模式切换。候选：
1. 手写 CSS + BEM
2. Tailwind CSS 4（CSS-first 配置 + CSS 变量令牌）
3. 组件库 CSS-in-JS（如 styled-components / vanilla-extract）

## 决策

采用 **Tailwind CSS 4 + CSS 变量设计令牌**：

- 设计令牌（`--background/--foreground/--card/--muted/--ring/--border...`）定义在 `@theme` 与 `:root` / `.dark` 中，组件通过 `bg-card`、`text-muted-foreground` 等语义类消费
- 暗色模式通过 `class` 策略（`<html class="dark">`）+ 内联脚本防 FOUC（`index.html` 首帧同步应用）
- 不引入 UI 组件库的运行时：shadcn-vue 仅作为**代码复制式**组件源（copy-paste 模式），保证可定制与体积

## 后果

**正面**
- 视觉令牌统一 → 全站主题切换只需改 12 个 CSS 变量
- 无运行时样式开销（构建期生成原子类，CSS gzip 仅 ~7KB）
- 设计语言克制：单一边框色、语义灰阶、无炫技渐变

**负面 / 权衡**
- 原子类让模板类名较长（由组件封装吸收，页面不直接堆 class）
- 语义令牌需维护命名纪律（code review 检查硬编码色值）

**不选方案 1/3 的原因**：BEM 类名爆炸且暗色模式靠手写覆盖；CSS-in-JS 有运行时开销且与本项目"Vite + 现代 CSS"方向不一致。
